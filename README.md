# maldev-labs

Windows C++ / WinAPI learning labs. Educational use only.

## Labs

- [01 — Local Shellcode Loader](01-shellcode-loader/)  
  Local execution with `VirtualAlloc`, `memcpy`, `VirtualProtect`, and `CreateThread`.

- [02 — XOR Payload Loader](02-xor-payload-loader/)  
  Offline XOR encryption and runtime decryption of Notepad payload.

- [03 — Base64 Encoder and Decoder](03-base64-tool/)  
  Base64 encoding and decoding with the Windows Crypt32 API.
